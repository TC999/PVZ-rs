# 06 · 行为规格：必须与 C++ 保持一致的东西

> 这是"等价"的定义。凡与本文件冲突的翻译都视为错误，不论代码是否"更合理"。

## 1. 等价的判据

1. **回放等价（最高标准）：** 用 C++ 版录制 `.dmo`；Rust 版回放同一 `.dmo`，每隔 N 帧的**状态哈希**（见第 7 节）必须与 C++ 一致。
2. **存档等价：** Rust 读取 C++ 存档并重新导出，与 C++ 导出一致；反之亦然。
3. **资源等价：** 同一份 `main.pak` + `properties/`，解析出的资源条目数、字符串条目数一致。

## 2. 随机数

- RNG 算法、种子来源、每次调用的消耗次数必须与 C++ 完全一致。
- **调用顺序即规格。** 任何改变"谁先调用 RNG"的重构（并行化、迭代顺序变化、提前计算、延迟计算）都会破坏回放。
- 不得使用 `rand` crate 等替代。
- 若 C++ 中有多个独立 RNG（如逻辑 RNG 与界面/特效 RNG），必须保持分离，不得合并。【待核对：实际有哪几个】

## 3. 数值

| 主题 | 规则 |
|---|---|
| 位宽 | 与 C++ 一致（`int`→`i32`，`float`→`f32`） |
| 整数溢出 | 原代码依赖回绕的位置用 `wrapping_*`；不依赖的位置若在原版中实际会溢出，登记到 UB 清单 |
| 整数除法/取模 | 均向零截断，符号随被除数；**除数为 0 时 C++ 是 UB、Rust 会 panic**，见 UB 清单处理 |
| float→int | `as i32`；C++ 对超范围值是 UB，Rust 饱和。遇到可能超范围的位置登记 |
| 浮点运算顺序 | **不得重排**（结合律不成立）；`a*b+c` 不得改写为 `mul_add`（FMA 会改变结果） |
| 浮点常量 | `1.0f` 对应 `1.0_f32`；不要写成 `f64` 字面量再转换 |
| 数学函数 | 经 `sexy_core::math` 封装，见 ADR-004 |
| 编译器优化 | 不启用会改变浮点语义的选项（如 fast-math 类） |

## 4. 帧与更新顺序

- 游戏逻辑为固定步长更新；更新顺序（Board 内各对象类别的更新次序、每类对象内部的遍历次序、更新前后绘制的时机）**必须与 C++ 逐一致**。
- 遍历对象池的方式（按下标顺序、跳过空槽、遍历中允许新增/删除对象）必须保持相同的语义：
  - 遍历中新增的对象本帧是否会被处理？
  - 遍历中被删除的对象是否还会被访问？
  - 【待核对：由 AI 对照 C++ 的 `DataArray` 遍历实现写出结论，填入此处】
- 帧计数、时间累积的初始值与类型必须一致。

## 5. 存档与文件格式

| 文件 | 规则 |
|---|---|
| `user*.dat`、`users.dat` | 与原版格式完全兼容（含 2038 年问题的兼容性处理）。【待核对：实现细节】 |
| `*.v4` | TLV 格式。新增字段用新 ID，不得复用旧 ID；缺失字段使用默认值；定宽基本类型逐字段读写，**不得做结构体整体转储** |
| `*.dat`（旧 mid-level） | 原始内存转储，布局依赖平台；只做读取迁移（若 ADR-009 同意），不要写出 |
| 字节序 | 存档格式使用显式字节序读写，不依赖主机字节序 |
| `cache32/cache64` | 本地缓存，不要求兼容；校验失败时重新生成 |
| `.dmo` | 录制回放格式，必须与 C++ 版互通 |
| `registry.regemu` | 设置模拟，格式以 C++ 为准 |

## 6. 文本与资源

- 内部统一 UTF-8。
- 读取 `LawnStrings.txt`：处理 BOM；处理 Windows-1252 → UTF-8 的转换。
- `properties/default.xml`、`properties/Layout.xml`：在 `LawnStrings.txt` **之后**加载，可覆盖字符串；两者缺失时使用内置英文默认值。
- 不同版本资源包（1.2.0.1073 EN、1.2.0.1093 DE/ES/FR/IT、1.1.0.1056 ZH、Steam 1.2.0.1096）的**字符串键差异不在引擎里修补**，保持与 C++ 一致的行为。

## 7. 回放哈希（用于验收）

状态摘要至少包含（【待核对：确定最终字段，并与 C++ 端导出工具保持一致】）：

- 帧号
- RNG 当前状态
- 阳光、金币、关卡进度等标量
- 所有植物、僵尸、子弹、金币、格子物品：类型、位置、血量、计数器、状态
- 当前波次、僵尸生成相关计数

做法：C++ 与 Rust 两端在同一帧间隔输出同格式的摘要（文本或哈希），用脚本逐帧对比；**第一个不一致的帧号**是排查起点。

## 10. AI 容易犯的错误（发现一次，补一条）

- 把 `f32` 悄悄改成 `f64`
- 把带副作用的循环改成迭代器链，导致执行顺序变化
- 在加载线程中调用了 GL
- 子线程 panic 没有传播，导致界面"假死"
- 把 C++ 里的 `switch` fallthrough 漏掉
- 把"原版看起来是 bug"的逻辑顺手修正
- 为了过编译，把复杂逻辑替换成 `todo!()` 或空实现且没有登记
- 用 `unwrap_or_default()` 掩盖了应该报错的路径
